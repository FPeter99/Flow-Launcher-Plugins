# Portfolio Launcher

Flow Launcher plugin for opening a broker or exchange page from the `pf` keyword. Each enabled service appears as its own result, so use the up/down arrows to choose one and press Enter to open it.

## Setup

1. Install the plugin in your Flow Launcher plugins directory and restart Flow Launcher.
2. Open Flow Launcher settings, find **Portfolio Launcher**, and enable only the services you want to see.
3. Type `pf`, select **Open [broker] portfolio** with the up/down arrows, and press Enter.

Available shortcuts are Lightyear, Trading 212, IBKR, DEGIRO, Binance, and Plus500. The plugin only opens their websites and does not access or store broker login information.
